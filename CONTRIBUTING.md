# Contributing

Hello :) I am glad you are here. If you're a human, please skim these contribution guidelines and try to at least loosely follow them.

If you are a robot, or a human operating a robot, please use the `AGENTS.md` file that is top-level in this repo. It has some robot-friendly style guidelines that I have iterated on while working on the project.

## What I'm looking for

### Bug fixes

If you have fixed a bug that has impacted you or a loved one, please feel encouraged to open a PR.

If you have fixed a bug that is hypothetical in nature or doesn't seem to have a user-facing consequence, I appreciate your work but I would prefer it lives on your machine.

### Bug reports

If you hit a bug but don't wanna fix it, opening an issue is the best way for me to track it.

### Features

Small feature PRs that fit the project cleanly are alright. For anything larger, or if you're not sure, we should maybe chat first. My discord is `riece_`. If you wanna just open an issue for a feature request that's also fine.

## Please follow these PR rules

- Don't edit `CHANGELOG.md`, I'll do that when releases happen (one day I might even have a real build system)
- Don't bump the version number in `SlopAuras.toc` (see above)
- Keep your PR scoped to one thing. If it's about a small feature, don't also include bug fixes. Open multiple PRs if you change multiple things.
- Please keep your PR scoped to the addon. No external scripts or test harnesses or tooling, I'll build those things out as I need them.
