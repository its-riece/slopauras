# 0.4.0

## New

- Editing is now supported while in combat (you'll take a perf hit when doing so)
- Test mode! Lets you choose which groups you wanna test. For testing party/raid displays I recommend you `/edit` then `/slop` and then start your test. You can use default edit mode frames to see your auras.
- Settings massively reorganized

## Fixed

- The whole ding dang thing was broken in BGs. It works now but if you edit stuff you'll incur the same performance cost as editing in combat.
- Several perf bugs. Still expect some stuttering the first time you join a large raid, but much much better than it was.
